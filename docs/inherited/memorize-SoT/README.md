# memorize 설계 기준 문서(SoT)

> 전신 프로젝트의 기록이다. mori의 현재 요구사항은 아니다.
> 2026-09-24에 안내 문구를 한국어로 정리했으며, 기존 결정과 문서 식별자는 유지했다.

memorize의 동기화·작업공간·기억 아키텍처를 지탱하는 불변 조건과 확정된 결정들이다.
2026-07-01 설계 논의에서 추려냈다. 과거 설계 판단을 살펴볼 때는 이 문서들을 먼저 확인한다.
확정된 내용은 개별 문서에, 미결 내용은 `900-open-decisions.md`에 있다.

## 상태 범례

- **불변(Invariant):** 추가만 가능한 이벤트 로그, 합집합 동기화, 로컬 우선 구조가 강제하는 조건이다.
  바꾸려면 설정이 아닌 모델 자체를 바꿔야 한다.
- **결정(Decision):** 의도적으로 선택한 사항이다. 무엇을 대체하는지 밝힌 새 문서나 수정 문서가
  나오기 전까지 유효하며, 조용히 바꾸지 않는다.
- **미결(Open):** 아직 확정하지 않은 사항이다. 확정된 내용으로 오해하지 않도록 `900`에 둔다.

## 기록 규율

이 문서 묶음에도 시스템의 이벤트 로그와 같은 ‘추가하고 대체하기’ 원칙을 적용한다.
확정된 문서를 제자리에서 덮어쓰지 않는다. 불변 조건이나 결정을 바꿀 때에는 대체 문서를
추가하거나 `대체됨:`을 지정하고, 이전 문서를 판단 경위의 기록으로 남긴다.
행 삭제 대신 철회 기록을 사용하는 것과 같은 원리다(`050` 참고).
